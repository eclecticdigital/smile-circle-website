# Smile Circle Five Dock — website rebuild (preview)

Static home page and contact page for Smile Circle Dental Clinic, Five Dock NSW.

- `index.html` — home page (`/`)
- `contact-us/index.html` — contact page (`/contact-us/`)
- `assets/` — stylesheet, script, images
- `docs/` — generated GitHub Pages build (path-prefixed copy; run `python3 build-pages.py` after editing)

Preview locally:

```bash
python3 -m http.server 8094
```
